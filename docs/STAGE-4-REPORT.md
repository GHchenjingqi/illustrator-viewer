## 2. 渲染能力

- 原生 Canvas 2D，不依赖 PDF.js。
- DPR 高清适配（最高 3x）。
- 画板居中 + 适应窗口；滚轮以鼠标为中心缩放；拖拽平移；1:1；全屏。
- 多画板下拉切换。
- 非零 / evenodd 填充；描边、虚线、端点、连接、斜接。
- 复合路径合并为单个 Path2D 填充。
- 非打印图形跳过。
- 渐变/专色使用近似纯色，界面显示“部分预览”提示。
- 嵌入图片、裁剪、透明度、文字对象不绘制，并明确列出。
